# Proyecto de sprint_9 Tripleten

Este proyecto tiene la finalidad de realizar diferentes tipos de regresiones desde la lineal, cuadrática, cúbica,
exponencial, logaritmica, log´sitica, potencial, SVR y series de fourier. Estas dos últimas para funciones no lineales.  

Se utilizara realiza tambien el cálculo de métricas como el R2 para determinar el grado de exactitud del modelo y sus 
variaciones con respecto a los puntos originales.

Se utilizaran las siguientes librerias:

- pandas
- numpy
- matplotlib
- seaborn
- sklearn
- archivo "requerimets.txt" para compatibilidad y reproducción del código
- Regresiones_ML.ipynb
